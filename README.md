## 가입 단계와 소요 시간

OKX 가입은 6단계로 끝납니다. 계정 생성 자체는 5분 안쪽이고, 시간을 잡아먹는 건 KYC 대기입니다. 아래 시간은 2026년 11월 14일 공개된 모바일 앱 기준 가이드 영상에서 안내한 값입니다.

| --- | --- | --- | --- |
| 1. 국가 설정·약관·이메일 | 이메일 주소 | 1~2분 | 국가가 '대한민국'으로 되어 있는지 확인. 레퍼럴 코드 칸이 비어 있으면 수동으로 입력 |

| 3. KYC 신원인증 | 신분증 | 보통 10~30분 | 앱에서 진행. 신분증 앞면·뒷면 촬영 후 실시간 얼굴 인증, 도로명 주소와 우편번호 입력 |

## 가입 전에 알아야 할 실제 거래 비용

OKX에는 SaaS처럼 월·연 요금제가 없습니다. 수익 구조는 거래 수수료이고, 일반 등급 기준 수치는 2026년 10~11월에 OKX 공식 수수료 페이지를 확인해 정리된 자료에서 동일하게 나옵니다.

| 구분 | 일반 등급 수수료 | 예시 |
| --- | --- | --- |
| 현물 지정가(maker) | 0.08% | 1,000 USDT 주문 시 0.80 USDT |
| 현물 시장가(taker) | 0.10% | 1,000 USDT 주문 시 1.00 USDT |
| 선물 지정가(maker) | 0.02% | 포지션 가치 기준으로 계산 |
| 선물 시장가(taker) | 0.05% | 5,000 USDT 포지션 진입 시 2.50 USDT |

선물 수수료는 레버리지와 무관하게 포지션 가치에 비율을 곱해 매깁니다. 20배로 진입해도 5,000 USDT 포지션이면 같은 2.50 USDT입니다. 여기에 펀딩비가 별도로 붙고, 강제청산 시에는 청산 손실 위에 현재 taker 수수료가 더해집니다.

지역별로 요율이 다릅니다. 미국·UAE·EU 사이트는 자체 스케줄을 쓰고, EU 소매 계정은 perpetual 레버리지가 10배로 제한된다는 정리도 있습니다. 한국 계정에 적용되는 정확한 요율과 레버리지 상한은 이 글에서 확인한 자료에 없으니, 주문 화면에 표시되는 값이 기준입니다.

## 가입 전 제한과 리스크

가입 자체를 막는 요소는 크게 네 가지입니다.

1. KYC 필수. 신분증과 얼굴 인증을 통과하지 못하면 입금도 거래도 되지 않습니다.
2. 국가 설정. 첫 화면에서 '대한민국'이 맞는지 확인하세요. 잘못 선택하면 이후 서비스 이용 범위가 달라질 수 있습니다.
3. 네트워크 불일치. TRC20으로 받을 주소에 다른 네트워크 코인을 보내면 복구가 어렵습니다.
4. 추천 코드 사후 변경 불가 가능성. 가입 완료 후 코드를 새로 넣는 절차는 확인되지 않았습니다.

선물거래는 여기에 별도의 위험이 붙습니다. 가이드 영상도 이 부분은 직접 경고합니다.

> 선물거래는 레버리지를 활용하기 때문에 가격 변동에 따라 손실이 확대될 수 있습니다. 거래 전 수수료, 증거금, 청산 위험을 충분히 확인하시기 바랍니다.

마진 모드는 크로스와 아이솔레이티드로 나뉩니다. 크로스는 선물 지갑 전체 자산을 포지션에 활용하고, 아이솔레이티드는 해당 포지션에 배정한 자산만 씁니다. 처음이라면 아이솔레이티드에 낮은 배율로 시작하는 편이 손실 범위를 파악하기 쉽습니다. 주문 전 TP/SL에 익절가와 손절가를 미리 걸어두면 화면을 계속 보지 않아도 포지션이 자동 종료됩니다.

**CASH20 혜택은 얼마인가요?**
금액은 확인되지 않았습니다. 링크에 코드명만 있을 뿐 혜택 수치가 공개된 페이지에 없습니다. 가입 후 리워드 페이지에 표시되는 조건이 실제 기준입니다.
